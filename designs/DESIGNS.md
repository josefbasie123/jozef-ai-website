## Structure

```
designs/
  MAIN/           ← current live design (copy before experimenting)
  <NAME>/         ← alternative or archived designs
  DESIGNS.md      ← this index
```

To test a new design: duplicate MAIN into a new folder, edit there, then swap back if needed.
